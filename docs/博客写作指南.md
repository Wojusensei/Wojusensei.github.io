# 博客写作指南（本地文档，不会出现在网站上）

## 发一篇文章

1. 在 `src/content/blog/` 下新建 `.md` 文件（文件名即链接，建议英文，如 `my-post.md`）；
2. 开头写 frontmatter：

```markdown
---
title: 标题
description: 一句话摘要（显示在列表卡片里）
date: 2026-09-01
tags: [标签1, 标签2]
---

正文用 Markdown 写。
```

3. 推送到 `main` 分支后 GitHub Actions 自动构建发布，一两分钟后在 https://wojusensei.github.io 生效。

## 换打赏码

把微信「赞赏码」（微信 → 收付款 → 赞赏码）或支付宝「收款码」截图放进 `public/donate/`，
替换 `wechat-qr.svg` / `alipay-qr.svg`（用 png 也行，同步改 `src/data/site.ts` 里的文件名）。

## 改作品卡片

编辑 `src/data/works.ts`：一个仓库一张卡片，`featured: true` 的显示在…（首页已精简，现在只在 /works/ 页展示）。字段：`name` 名称、`desc` 中文描述、`descEn` 英文描述、`tags` 标签。

## 改任何文字

全站文案在 `src/i18n/ui.ts`（中文在上半部分，英文在 `en:` 里）。

## 评论系统

当前未启用评论。（曾试用 utterances，因导航栏头像需求受其跨域策略限制，已按站长要求整体移除。如需恢复，utterances 配置简单：基于 GitHub Issues，无需安装 App。）

## 本地预览 / 发布

```bash
npm run dev      # 本地 http://localhost:4321
npm run build    # 构建到 dist/
git push         # 推送 main 即自动部署
```
